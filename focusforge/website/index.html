Install FocusForge 🚀

FocusForge is currently in Private Developer Preview and is not yet available on the Chrome Web Store. To install it manually:

  1. Download the extension using the button below and extract it.
  2. Open a new tab and go to chrome://extensions/
  3. Toggle Developer mode ON in the top right.
  4. Click Load unpacked.
  5. Select the extracted focusforge project folder on your PC.
